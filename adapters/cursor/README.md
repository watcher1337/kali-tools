# Cursor adapter

Cursor documents project skill roots at `.agents/skills/` and `.cursor/skills/`, and global roots at `~/.agents/skills/` and `~/.cursor/skills/`. Copy selected directories from this repository's `skills/` under one root. Cursor discovers skills at startup and also supports manual selection from the Agent chat.

Do not replace a skill with a Cursor rule; preserve its directory and supporting files.

Source: <https://cursor.com/docs/skills>. **Status:** documentation-linked; runtime installation is not tested in this checkout.
